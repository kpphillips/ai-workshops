Claude 5.5: Haiku, Sonnet and Opus

Anthropic shipped Opus 5.5 on September 22, 2026, Sonnet 5.5 six days later and Haiku 5.5 on October 7. This page covers all three, with Fable 5.1 where it is the tier above. Every lab either checks a published number or runs a test you can repeat with your own key, and module 11 helps you choose which model to start with.

A price that changed after launch Quoted The Sonnet 5.5 launch page (September 28) still lists cache reads at $0.20 per million tokens. Every Sonnet 5.5 price line is now exactly half the matching Opus 5.5 line. Opus 5.5's cache read is still $0.20.
The case study Northgate Print & Sign is a fictional 12-person print shop. Its inbox and its billing code supply the test tasks: an order buried in an email thread, and an invoice function with three bugs. Both have automatic checkers, so every run ends in a pass or fail you can count.

3. Sweep effort instead of guessing

Effort is the main control on all three models, and the API defaults differ: medium for Haiku 5.5 and Opus 5.5, high for Sonnet 5.5. Haiku 5.5 is the first Haiku with effort levels, and it supports all five. Run the order-extraction task at each level and read tokens, time and the checker result side by side.

Effort sweep on the Northgate order

Test it yourself
Effort levels

Haiku 5.5 note: Anthropic's prompting guide says that at xhigh in multi-turn chats the model sometimes writes its whole answer in its thinking and ends the turn with no visible text, so this lab flags an empty reply. It also says thinking: {"type":"disabled"} returns a 400 at xhigh and max; this lab never sends it Quoted.

Haiku 5.5 reacts to effort more than the larger models Quoted In the system card (section 8.11.3), Haiku 5.5's length-adjusted HealthBench Professional score rose from 57.9% at low to 59.9% at medium (the API default) and 64.8% at max, while Sonnet 5.5, Opus 5.5 and Fable 5.1 each moved by less than 2 points across the five levels. Answers took 8 to 21 seconds from low to xhigh and about 110 seconds at max. On GDPval-AA the default medium scored 1277 Elo using about a tenth of the output tokens that max used, which scored 1620 (section 8.10.2). Anthropic's published Haiku 5.5 scores are at max effort, so run your own sweep at the effort you ship.
Creator claim under test A creator benchmark ("Skatebench") reportedly showed max effort using about 15 times the tokens for a one-point gain. We could not review that data. The closest published evidence: on FrontierCode, Sonnet 5.5 scored 46.2% at max and 52.1% at xhigh, because at max it more often launched review subagents and made out-of-scope edits Quoted.

7. Drop reflex thinking lines, and handle refusals by category

  
Anthropic found that removing "think carefully" from an Opus 5.5 chat prompt made replies start sooner with no clear quality drop, while the Sonnet 5.5 guide adds a think-first line for JSON reasoning tasks. Declines arrive as normal responses with a category, and each category has its own fallback; Haiku 5.5 has none.

8. Tag pasted text so it can't give orders

  
Opus 5.5 resists instructions hidden in tool results and web pages better than earlier Opus models, but its system card says it is more likely than previous models to follow instructions in text a user pastes. Anthropic's fix is a tag with a random ID plus one system note, and this lab tests it on a thread with a planted instruction.

10. Route by cost per passing task

  
Sonnet 5.5 is two Elo points behind Opus 5.5 on GDPval-AA, yet Anthropic says Opus stays clearly stronger on complex open-ended work. For prompts up to 100K tokens Haiku 5.5's input price is one twentieth of Sonnet 5.5's, and Anthropic says it is best for narrowly scoped work. Run both checkable tasks on the models you tick and let the cheapest passing configuration write your routing rule.

    Benchmark trap
    Opus 5.5's Chartography score is 89.0% on its own launch page, measured with tools. The Sonnet 5.5 page lists Opus 5.5 at 64.4% without tools, next to Sonnet 5.5 at 61.6% Quoted. The Haiku 5.5 launch table has the same trap: it shows FrontierCode Main at 46.4% for Haiku 5.5 beside 52.1% for Sonnet 5.5, but 52.1% is Sonnet's best score, at xhigh. At max, the effort Haiku 5.5 was run at, Sonnet 5.5 scored 46.2% (system card, section 8.3) Quoted. Only compare rows run under the same conditions.
  






  

  
11. Pick the model for the job

  
Anthropic's model guide gives two ways to start: efficiency-first, beginning with Haiku 5.5 and moving up only where it falls short, or capability-first, beginning with Opus 5.5 and moving down as your evals allow. It adds that tuning effort "is often a better lever than switching models." Choose a model for each task below, then see what the sources say. There is no score: several picks are defensible, and the point is to see what each one buys and risks.

    From Anthropic's Opus 5.5 publications Quoted
    The system card says that in internal use "the top subcategory of flagged behavior was asserting unverified inferences as established fact." The launch post reports "signs that Opus 5.5 often suspects it is being evaluated," which limits how well any test, including the ones on this page, predicts real-world behavior. The Sonnet 5.5 system card was not reviewed for this workshop; Sonnet facts here come from its announcement and docs.
  
    
  
    
    From Anthropic's Haiku 5.5 publications Quoted
    The system card reports that in its automated audit Haiku 5.5 "over-refused more than any other model we tested," that it "hallucinated more than other recent models," and that it used a leaked answer without telling the user 17% of the time, against 2% for Haiku 4.5 (section 6.1.2). Its published benchmark scores are at max effort, and the default is medium. Workshop judgment Verify Haiku 5.5 on a sample of your own tasks before you let it run unattended.
