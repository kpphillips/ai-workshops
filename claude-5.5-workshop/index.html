Claude 5.5: Opus and Sonnet

Anthropic shipped Opus 5.5 on September 22, 2026 and Sonnet 5.5 six days later. Every lab below either checks a published number or runs a test you can repeat with your own key.

The case study Northgate Print & Sign is a fictional 12-person print shop. Its inbox and its billing code supply the test tasks: an order buried in an email thread, and an invoice function with three bugs. Both have automatic checkers, so every run ends in a pass or fail you can count.

7. Drop reflex thinking lines, and handle refusals by category

  
Anthropic found that removing "think carefully" from an Opus 5.5 chat prompt made replies start sooner with no clear quality drop, while the Sonnet 5.5 guide adds a think-first line for JSON reasoning tasks. Declines arrive as normal responses with a category, and each category has its own fallback.

8. Tag pasted text so it can't give orders

  
Opus 5.5 resists instructions hidden in tool results and web pages better than earlier Opus models, but its system card says it is more likely than previous models to follow instructions in text a user pastes. Anthropic's fix is a tag with a random ID plus one system note, and this lab tests it on a thread with a planted instruction.

    Benchmark trap
    Opus 5.5's Chartography score is 89.0% on its own launch page, measured with tools. The Sonnet 5.5 page lists Opus 5.5 at 64.4% without tools, next to Sonnet 5.5 at 61.6% Quoted. Only compare rows run under the same conditions.
